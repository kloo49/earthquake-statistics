# Property Damage due to Geology and Depth of Earthquake

[Final Blog Post](https://kloo49.github.io/earthquake-statistics/reports/blog-post.html)

This project aims to link the statistical relationship between earthquakes in the United States with geology and epicenter depth, and its effect on property damage.

## Data
- Earthquake data from Jan-01-2016 to Oct-31-2026 is from the USGS, specifically for the United States. This analysis focuses on the earthquake's depth, latitude, longitude, and magnitude.
